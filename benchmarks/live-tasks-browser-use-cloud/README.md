# Eight live tasks: pilotfish against Browser Use Cloud

Eight everyday tasks on live sites, each run on the pilotfish app and on Browser Use Cloud, both on GPT-6 Luna (Browser
Use at its High setting) with a US browser. The round ran on 5 Nov 2026; four tasks (Zillow, Walmart, Google Flights,
Yahoo Finance) were run again on pilotfish after fixes that week, and their pilotfish time is the mean of those later
runs. Every answer was checked against the live site at the time. This is our own comparison: there is no runner or
third-party judge for it.

| Task | pilotfish answer | pilotfish time | Browser Use Cloud time |
|---|---|---|---|
| Best Buy: the 3 cheapest RTX 5080 cards, exact names | Correct | 3:20 | 12:25 |
| Zillow, 78704: result count and the cheapest listing | Correct | 1:29 (mean of 3 runs) | 1:57 |
| Walmart: a 65-inch TCL TV, model, price and rating | Correct | 1:02 (mean of 3 runs) | 0:42 |
| Kelley Blue Book: value of a 2020 Honda Civic LX | Correct | 4:20 | 19:07 |
| Booking.com: the first 3 Lisbon stays rated 9+ by price | Correct | 0:45 | 1:50 |
| Amazon: Anker 737 power bank, price and rating | Correct | 0:46 | 1:04 |
| Google Flights: SFO to JFK round trip, both legs and the total | Correct | 3:48 (mean of 3 runs) | 5:00 |
| Yahoo Finance: Apple's last close | Correct | 1:23 | 0:55 |
| **All 8** | **8 correct** (Browser Use Cloud: 8 correct) | **16:53** | **43:00** |

Totals for the eight tasks:

| | pilotfish | Browser Use Cloud |
|---|---|---|
| Time | 16:53 | 43:00 |
| Cost, everything recorded for the runs | $0.202 | $0.69 (as billed) |
| Model spend alone | $0.091 | $0.207 |

pilotfish was faster on 6 of the 8 tasks; Browser Use Cloud was faster on Walmart and Yahoo Finance. The median task
took 1:26 on pilotfish and 1:54 on Browser Use Cloud. Most of the total-time gap comes from two tasks (Best Buy and
Kelley Blue Book). Prices and listings moved between runs (Google Flights fares, Zillow's result count), so the answers
were checked against what each site showed at the time.
