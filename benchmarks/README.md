# Benchmarks

The runs behind the figures on [pilotfish.gai.ventures/benchmarks](https://pilotfish.gai.ventures/benchmarks), and
other runs we keep for the record. Every file here is the pilotfish team's own run; nothing is a third party's
verified score.

| Folder | What it is | On the website |
|---|---|---|
| [`webvoyager-100/`](webvoyager-100/) | LangChain's 100 WebVoyager tasks, pilotfish open MCP against Playwright MCP on GPT-6 Luna, 11 Nov 2026: runner, task file and every result row | Yes: tokens, tool calls, latency and model cost |
| [`live-tasks-browser-use-cloud/`](live-tasks-browser-use-cloud/) | Eight live tasks, pilotfish app against Browser Use Cloud on GPT-6 Luna, 5 Nov 2026: each task, answer and time | Yes: time, cost and model spend |
| [`online-mind2web/`](online-mind2web/) | Online-Mind2Web runs: 60 tasks × 2 trials against open-source browser-use (25 Oct 2026, Claude models), and a 10-task GPT-6 Luna check (18 Nov 2026) | No |

If you rerun any of these, please open an issue with your numbers, whichever way they go.
