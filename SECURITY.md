# Security

## Reporting a vulnerability

Please do not open a public issue. Email **support@gai.ventures** with what you found, how to reproduce it, and the
version (`npx @gaiventures/pilotfish-mcp --version`), as described on <https://pilotfish.gai.ventures/security>.
We will acknowledge your report and keep you posted on the fix.

## Supported versions

The latest version of `@gaiventures/pilotfish-mcp` and `@gaiventures/pilotfish-mcp-managed` on npm.

## Scope

This repository holds the local MCP (it drives a Chrome on your own machine) and the managed relay (it carries MCP
messages to pilotfish's hosted service). Issues with the hosted service itself go to the same address.
